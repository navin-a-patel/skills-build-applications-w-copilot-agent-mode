Backend notes: MongoDB

This backend includes Mongoose for MongoDB access.

Environment
- MONGO_URL: MongoDB connection string (defaults to mongodb://localhost:27017/octofit)

Files added
- src/db.ts — helper to connect to MongoDB using mongoose
- src/models/User.ts — example User model
- src/seeds/initDb.ts — seed script to populate example users

Quick start:
1. cd octofit-tracker/backend
2. npm install
3. copy .env.example to .env and adjust MONGO_URL if needed
4. npm run dev

Seed the database (creates example users, upserts on re-run):
1. Ensure MongoDB is running and MONGO_URL in .env points to the DB
2. npm run seed
